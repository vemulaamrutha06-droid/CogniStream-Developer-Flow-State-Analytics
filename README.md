# CogniStream
Developer Flow-State & Cognitive Load Analytics

## Project Overview
CogniStream analyzes developer activity indicators
such as focus score, cognitive load and productivity.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- Streamlit

## Features
- Dataset generation and cleaning
- Exploratory Data Analysis
- Interactive dashboard
- KPI cards and filters
- Data visualizations
- CSV download

## Dataset
The project currently uses 1,000 synthetic records
with 12 columns for demonstration.

## Run Dashboard
pip install -r requirements.txt
python -m streamlit run dashboard/app.py# CogniStream-Developer-Flow-State-Analytics
